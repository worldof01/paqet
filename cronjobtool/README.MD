## توضیحات پروژه

**Paqet CronJob Manager**
 یک ابزار قدرتمند و کاربردی برای مدیریت کرون‌جاب‌های سرویس‌های
 Paqet در لینوکس است. این اسکریپت به شما امکان می‌دهد به سادگی کرون‌جاب‌های مربوط به سرویس‌های systemd را مدیریت کنید، بدون نیاز به دانش عمیق از دستورات crontab یا systemd.

این ابزار با رابط کاربری تعاملی و友好的 طراحی شده است و تمامی عملیات‌های لازم برای مدیریت کرون‌جاب‌ها را پوشش می‌دهد. شما می‌توانید کرون‌جاب جدید اضافه کنید، فاصله زمانی آن را تغییر دهید، وضعیت فعلی را مشاهده کنید و در صورت نیاز کرون‌جاب‌ها را حذف کنید.

## ویژگی‌ها

این ابزار دارای ویژگی‌های متعددی است که آن را به یک راه‌حل جامع برای مدیریت کرون‌جاب‌ها تبدیل کرده است:

### مدیریت کامل کرون‌جاب

- **مشاهده لیست سرویس‌ها**: نمایش تمام سرویس‌های Paqet به همراه وضعیت فعال بودن آن‌ها و وضعیت کرون‌جاب
- **اضافه کردن کرون‌جاب**: امکان تنظیم کرون‌جاب برای سرویس‌هایی که هنوز کرون‌جاب ندارند
- **ویرایش کرون‌جاب**: تغییر فاصله زمانی اجرای کرون‌جاب برای سرویس‌های مختلف
- **حذف کرون‌جاب**: حذف کرون‌جاب‌های موجود به صورت تکی یا دسته‌ای

### سیستم هوشمند تشخیص و رفع تکراری‌ها

- **تشخیص خودکار**: شناسایی خودکار کرون‌جاب‌های تکراری در crontab
- **رفع خودکار**: اصلاح خودکار کرون‌جاب‌های تکراری بدون نیاز به مداخله دستی
- **تأیید قبل از تغییر**: درخواست تأیید کاربر قبل از جایگزینی کرون‌جاب موجود

### رابط کاربری پیشرفته

- **رنگ‌بندی زیبا**: استفاده از رنگ‌های مختلف برای تفکیک بهتر اطلاعات
- **نمایش وضعیت**: نمایش وضعیت دقیق هر سرویس و کرون‌جاب مربوطه
- **پیام‌های informative**: نمایش پیام‌های واضح برای هر عملیات

## پیش‌نیازها

برای استفاده از این ابزار، سیستم شما باید دارای پیش‌نیازهای زیر باشد:

- سیستم‌عامل لینوکس (Ubuntu، Debian، CentOS، Fedora و ...)
- دسترسی ریشه (sudo) برای اجرای دستورات systemctl و crontab
- سرویس‌های Paqet نصب شده در مسیر `/etc/systemd/system/paqet-*.service`
- bash نسخه 4.0 یا بالاتر

## نصب و راه‌اندازی

برای نصب و استفاده از این ابزار، مراحل زیر را دنبال کنید:

### مرحله اول: دانلود اسکریپت

ابتدا اسکریپت را از مخزن GitHub دانلود کنید:

```

اسکریپت را اجرایی کنید:

```

اسکریپت را با دسترسی ریشه اجرا کنید:

```bash

```

## نحوه استفاده

پس از اجرای اسکریپت، منوی اصلی با گزینه‌های زیر نمایش داده می‌شود:

```
╔═══════════════════════════════════════╗
║   Paqet CronJob Manager by worldof01  ║
╚═══════════════════════════════════════╝

 1) List services & cronjob status
 2) Add cronjob to a service
 3) Edit / change cronjob interval
 4) Remove cronjob
 5) about
 0) Exit
```

### گزینه ۱: مشاهده لیست سرویس‌ها و وضعیت کرون‌جاب

این گزینه تمام سرویس‌های Paqet را به همراه وضعیت زیر نمایش می‌دهد:

- وضعیت سرویس (فعال یا غیرفعال)
- وجود یا عدم وجود کرون‌جاب
- فاصله زمانی کرون‌جاب (در صورت وجود)
- هشدار در صورت تکراری بودن کرون‌جاب

در صورت وجود سرویس‌های بدون کرون‌جاب، امکان اضافه کردن کرون‌جاب به آن‌ها فراهم می‌شود.

### گزینه ۲: اضافه کردن کرون‌جاب

با انتخاب این گزینه می‌توانید برای یک سرویس کرون‌جاب جدید ایجاد کنید. سیستم از شما می‌خواهد که فاصله زمانی اجرا را به دقایق وارد کنید (بین 1 تا 1440 دقیقه). اگر سرویس قبلاً کرون‌جاب داشته باشد، از شما تأیید گرفته می‌شود.

### گزینه ۳: ویرایش فاصله زمانی کرون‌جاب

این گزینه برای تغییر فاصله زمانی اجرای کرون‌جاب‌های موجود استفاده می‌شود. ابتدا لیست سرویس‌های دارای کرون‌جاب نمایش داده می‌شود و سپس می‌توانید سرویس مورد نظر و فاصله زمانی جدید را انتخاب کنید.

### گزینه ۴: حذف کرون‌جاب

با این گزینه می‌توانید کرون‌جاب‌های موجود را حذف کنید. امکان حذف تکی یا حذف تمام کرون‌جاب‌ها وجود دارد. قبل از حذف، تأیید کاربر گرفته می‌شود.

### گزینه ۵: درباره

اطلاعات نویسنده و پروژه به همراه آدرس کیف پول TON برای حمایت نمایش داده می‌شود.

## مثال‌های عملی

### مثال ۱: مشاهده وضعیت سرویس‌ها

```
$ sudo ./paqetcronjobtool.sh

 1) List services & cronjob status

=====================================
  Services & Cronjob Status
=====================================

 1) paqet-node
    Service Status : active
    Cronjob        : ✓ Active — every 5 minute(s)
    └─ */5 * * * * /bin/systemctl restart paqet-node >/dev/null 2>&1 # PAQET_AUTORESTART paqet-node

 2) paqet-api
    Service Status : active
    Cronjob        : ✓ Active — every 10 minute(s)
    └─ */10 * * * * /bin/systemctl restart paqet-api >/dev/null 2>&1 # PAQET_AUTORESTART paqet-api
```

  Add Cronjob
=====================================

    ✓  No cronjob — ready to add

    ⚠  Has cronjob: every 10 minute(s) — will be replaced if confirmed

 Select service (1-2): 1

 ── paqet-node ──
 Current interval: every 5 minute(s)

 Restart every how many minutes? (1-1440): 15

 [✓] Cronjob set: paqet-node — every 15 minute(s)

## عیب‌یابی

### خطای "Please run with sudo"

این ابزار نیاز به دسترسی ریشه دارد. حتماً با `sudo` اجرا کنید:

```bash
sudo ./paqetcronjobtool.sh
```

### سرویس‌های Paqet یافت نشد

اطمینان حاصل کنید که سرویس‌های Paqet در مسیر `/etc/systemd/system/paqet-*.service` وجود دارند. نام فایل‌ها باید به فرمت `paqet-*.service` باشد.

### کرون‌جاب‌های تکراری

این ابزار به صورت خودکار کرون‌جاب‌های تکراری را تشخیص داده و اصلاح می‌کند. برای اجرای دستی این عملیات، گزینه 1 (List services) را انتخاب کنید.
